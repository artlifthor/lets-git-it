# Powerlifting Programming Manual

An evidence-based study text and quick reference on powerlifting programming, for coaches.
Built with [Astro Starlight](https://starlight.astro.build/) and published at
https://artlifthor.github.io/lets-git-it/.

## Run it on your computer

```
npm install
npm run dev
```

Then open http://localhost:4321/lets-git-it/.
